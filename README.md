# Бриф на сайт GrandDecor

Онлайн-форма брифа для сайта GrandDecor, агентства праздников в Ташкенте.

**Открыть форму:** https://proteacherwebs.github.io/granddecor-brief/

## Как пользоваться

1. Откройте ссылку и ответьте на вопросы. Вопросы со `*` — главные, остальные можно пропустить.
2. Ответы сохраняются автоматически в вашем браузере. Можно закрыть страницу и вернуться позже на том же устройстве.
3. Когда закончите, нажмите «Отправить в Telegram». На телефоне откроется меню «Поделиться». На компьютере текст скопируется и откроется Telegram: вставьте текст в чат.
4. Можно также скопировать ответы или скачать их файлом .txt.

## Приватность

Ответы, которые клиент вводит в форму, хранятся в браузере того, кто заполняет форму, и никуда не отправляются, пока он сам не нажмёт кнопку. Кнопка «Очистить» удаляет их из браузера.

## Файлы

- `index.html` — форма: один файл без внешних библиотек.
- `brief-questions.md` — те же вопросы текстом.
- `brief-answers.md` — ответы, которые уже известны со слов исполнителя.
